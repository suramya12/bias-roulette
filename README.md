# Bias Roulette

Spin a wheel of idols, a showdown picks one, spin a wheel of that idol's songs, a second showdown picks one, and the music video plays in the page. Static site, no dependencies, no build step.

## Run it

```bash
npm start
```

Open the address it prints. It also prints a `http://192.168...` address for your phone on the same Wi-Fi. Don't open `index.html` straight from disk: YouTube refuses players without a web address (player error 153).

```bash
npm test
```

runs the game-logic tests.

## Files

| Path | What it is |
|---|---|
| `data/roster.json` | Groups, shared song sets and idols. Edit songs here. |
| `data/overrides.json` | Your manual video picks. Never written by scripts. |
| `data/videos.json`, `data/dropped.json` | Generated by the resolver. Don't edit. |
| `REVIEW.md`, `DROPPED.md` | Generated reports: every match, and what was left out. |
| `src/game.js` | Rules only (picking, scoring, phases). Tested. |
| `src/catalog.js` | Joins roster and videos. |
| `src/wheel.js`, `fx.js`, `sound.js`, `player.js`, `main.js` | Drawing, effects, audio, YouTube player, wiring. |
| `scripts/resolve.mjs`, `scripts/serve.mjs` | Video resolver, local server. |

## Changing songs or videos

1. Edit `data/roster.json` (add a title to a group's `songs`, a `sets` entry, or an idol's `solo`).
2. Run `npm run resolve`. It needs yt-dlp (`pip install yt-dlp`). Only new songs are searched.
3. Read `REVIEW.md`. Flagged rows are listed first.
4. To fix a match, add a line to `data/overrides.json` and run `npm run resolve` again:

```json
"IVE | LOVE DIVE": "https://youtu.be/Y8JFxS1HlDo",
"SOME ARTIST | Some Song": null
```

A link forces that video; `null` drops the song. Other options: `--refresh` (search everything again), `--retry-dropped`, `--recheck-flagged`, `--only "text"`.

The resolver rejects audio, lyric, visualizer, teaser, practice, live and broadcast uploads, prefers verified artist or label channels, and checks YouTube's embed page to see whether the video may play on other sites. Region locks can't be seen from one location; the player shows a "Watch on YouTube" link when a video fails.

## Testing the player

`http://localhost:5173/?forceVideo=VIDEO_ID` plays that ID on every result. `IX1dkYoLHVs` (age-restricted) and `_k7gZaDjTTM` (embedding blocked) show the fallback.

## Deploy

No build: upload `index.html`, `styles.css`, `src/` and `data/` to any static host. All paths are relative, so a sub-path works.

- **GitHub Pages**: push the folder to a repo, then Settings, Pages, Deploy from branch, `main`, `/ (root)`.
- **Netlify or Cloudflare Pages**: drag the folder into the dashboard, or connect the repo with no build command and the root as output folder.
